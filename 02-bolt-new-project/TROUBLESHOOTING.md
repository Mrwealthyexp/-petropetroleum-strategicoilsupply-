# Bolt.new Troubleshooting

## Push Failed

**Error:** "Failed to push to GitHub"

**Fix:**
1. In Bolt: Sign out, sign back in with GitHub
2. In GitHub: Check repo exists at `github.com/Mrwealthyexp/petropetroleum-strategicoilsupply`
3. Try: Export as ZIP → Manual push (see `03-github-repo/MANUAL-PUSH.md`)

## Build Errors

**Error:** "npm install failed"

**Fix:**
1. Check package.json syntax
2. In Bolt chat: "Fix npm install errors"
3. Wait for AI to resolve

## Missing Files

**Error:** No `app/` folder or components

**Fix:**
1. In Bolt chat: "Generate complete app folder structure"
2. Specify: "Create all page.tsx files and components"
