## 🚀 QUICK START (Top to Bottom)

### PHASE 1: ACCOUNTS (30 minutes)
1. Create GitHub account → github.com/signup
2. Create Netlify account → netlify.com (use GitHub login)
3. Create Bolt.new account → bolt.new (use GitHub login)
4. Buy/verify FreeName domain → freename.io

### PHASE 2: BUILD (2 hours)
5. Scaffold in Bolt.new → See `02-bolt-new-project/PROMPT.txt`
6. Push to GitHub → See `03-github-repo/PUSH-GUIDE.md`
7. Configure Netlify → See `04-netlify-deploy/SETTINGS.md`

### PHASE 3: BACKEND (1 hour)
8. Deploy Edge Functions → See `05-edge-functions/DEPLOY.md`
9. Test API endpoints → See `05-edge-functions/TEST-COMMANDS.sh`

### PHASE 4: FRONTEND (2 hours)
10. Build dashboard → See `06-frontend-code/COMPONENTS.md`
11. Add 3D globe → See `07-3d-globe/INTEGRATION.md`
12. Add Web3 → See `08-web3-integration/SETUP.md`
