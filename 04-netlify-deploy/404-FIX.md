# 404 Error Fix

## Problem
Site deploys but shows 404 on all pages.

## Root Cause
Next.js 15 defaults to server-side rendering. Netlify needs static files.

## Solution

### Step 1: Edit next.config.ts in Bolt.new

```typescript
import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  output: 'export',      // ← ADD THIS
  distDir: 'out',        // ← ADD THIS
  images: {
    unoptimized: true,    // ← ADD THIS (required for static)
  },
};

export default nextConfig;
```

### Step 2: Push to GitHub
- Bolt.new → GitHub icon → Push

### Step 3: Change Netlify Settings
- Site Settings → Build & deploy
- Publish directory: `.next` → **`out`**
- Save

### Step 4: Trigger Deploy
- Deploys → Trigger deploy → Deploy site
- Wait 2-3 minutes
- Green "Published" = fixed

## Verification

Visit: `https://YOUR-SITE.netlify.app/dashboard`

Should show dashboard, not 404.
