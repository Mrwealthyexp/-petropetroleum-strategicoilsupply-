## Solidity for PetroPulse Access NFTs

---

## CONTRACT: PetroPulseAccess.sol

Deploy to: Ethereum or Polygon

### Features
- ERC-1155 multi-token standard
- 3 tiers: Basic, Premium, Enterprise
- Mint price in ETH/MATIC
- Role-based access control

### Deploy Steps
1. Go to remix.ethereum.org
2. Create new file: `PetroPulseAccess.sol`
3. Paste contract code
4. Compile (Solidity 0.8.20)
5. Deploy to Polygon (cheaper gas)
6. Copy contract address
7. Add to Netlify env vars
